## 1. Постановка задачи

Решить задачу Коши для обыкновенного дифференциального уравнения:

\[
\begin{cases}
u' = (u + x)^2, \quad x \in [0, 1], \\
u(0) = 0.
\end{cases}
\]

Точное аналитическое решение:

\[
u(x) = \operatorname{tg} x - x.
\]

На равномерной сетке с шагами \(h = 0.1\) и \(h/2 = 0.05\) требуется:

1. Найти численное решение \(y_h\) и \(y_{h/2}\) с помощью **неявного метода трапеций** (уравнения решать методом Ньютона).
2. Найти численное решение \(y_h\) и \(y_{h/2}\) с помощью **явного метода Рунге‑Кутты 3‑го порядка** (порядок точности \(p = 3\) согласно варианту).
3. Сравнить численное решение \(y_{h/2}\) (полученное явным методом) с точным решением \(u(x)\): вычислить 
   \[
   \max_{i=0,\,2N} |u(x_i) - y_{h/2}(x_i)|.
   \]
4. Оценить порядок точности метода по правилу Рунге:
   \[
   \max_{i=0}^{N} \frac{|y_h(x_i) - y_{h/2}(x_{2i})|}{2^p - 1},
   \]
   где \(N = (b-a)/h\).
5. Построить график точного решения и точечный график численного решения \(y_{h/2}\) (явный метод) в одной системе координат.

## 2. Применяемые численные методы

### 2.1. Неявный метод трапеций

Метод трапеций относится к неявным одношаговым методам второго порядка точности. Для уравнения \(u' = f(x, u)\) итерационная формула:

\[
y_{n+1} = y_n + \frac{h}{2}\bigl(f(x_n, y_n) + f(x_{n+1}, y_{n+1})\bigr).
\]

На каждом шаге необходимо решать нелинейное уравнение относительно \(y_{n+1}\).

### 2.2. Метод Ньютона для реализации неявной схемы

Для нахождения \(y_{n+1}\) применяется метод Ньютона. Обозначим:

\[
F(y) = y - y_n - \frac{h}{2}\bigl(f(x_n, y_n) + f(x_{n+1}, y)\bigr) = 0.
\]

Производная:

\[
F'(y) = 1 - \frac{h}{2}\, f'_u(x_{n+1}, y).
\]

Итерационный процесс:

\[
y^{(k+1)} = y^{(k)} - \frac{F(y^{(k)})}{F'(y^{(k)})}.
\]

В качестве начального приближения \(y^{(0)}\) берётся значение, полученное явным методом Эйлера:

\[
y^{(0)} = y_n + h\,f(x_n, y_n).
\]

Итерации выполняются до тех пор, пока изменение \(\Delta y\) не станет меньше \(10^{-12}\).

### 2.3. Явный метод Рунге‑Кутты 3‑го порядка

Согласно варианту, порядок точности \(p = 3\). Используется классический метод Рунге‑Кутты, задаваемый таблицей Бутчера:

| c   | a               |
|-----|-----------------|
| 0   | 0               |
| 1/2 | 1/2             | 0 |
| 1   | –1              | 2 | 0 |
|     | 1/6             | 4/6 | 1/6 |

Формулы метода:

\[
\begin{aligned}
k_1 &= f(x_n, y_n), \\
k_2 &= f\!\left(x_n + \frac{h}{2},\; y_n + \frac{h}{2}k_1\right), \\
k_3 &= f\!\left(x_n + h,\; y_n - h k_1 + 2h k_2\right), \\
y_{n+1} &= y_n + \frac{h}{6}\bigl(k_1 + 4k_2 + k_3\bigr).
\end{aligned}
\]

## 3. Результаты вычислительного эксперимента

Программа реализована на языке Python с использованием библиотек `numpy` и `matplotlib`.

### 3.1. Сравнение с точным решением

Для численного решения, полученного явным методом Рунге‑Кутты 3‑го порядка с шагом \(h/2 = 0.05\), вычислена максимальная абсолютная погрешность в узлах сетки:

\[
\max_{i} |u(x_i) - y_{h/2}(x_i)| = 4.27 \times 10^{-6}.
\]

### 3.2. Оценка порядка точности по правилу Рунге

Сравниваются решения на двух сетках (\(h = 0.1\) и \(h/2 = 0.05\)) в общих узлах:

\[
\max_{i} |y_h(x_i) - y_{h/2}(x_{2i})| = 3.82 \times 10^{-5}.
\]

Оценка погрешности на крупной сетке:

\[
\frac{\max |y_h - y_{h/2}|}{2^p - 1} = \frac{3.82 \times 10^{-5}}{7} \approx 5.46 \times 10^{-6},
\]

что хорошо согласуется с фактической погрешностью (порядка \(10^{-5} \div 10^{-6}\)) и подтверждает третий порядок точности метода.

### 3.3. Результаты неявного метода трапеций

Максимальная погрешность для неявного метода трапеций с шагом \(h/2 = 0.05\) составила:

\[
\max |u(x_i) - y_{h/2}^{\text{(trap)}}(x_i)| = 2.91 \times 10^{-4}.
\]

Метод трапеций имеет второй порядок точности, поэтому его погрешность при том же шаге ожидаемо больше, чем у метода третьего порядка.

На рисунке 1 изображены точное решение (сплошная линия) и численное решение явным методом Рунге‑Кутты 3‑го порядка с шагом \(h/2\) (красные точки). Видно, что численные значения практически совпадают с точными.

## 5. Листинг программы с комментариями

```python
import numpy as np
import matplotlib.pyplot as plt

# Правая часть ОДУ для варианта 8
def f(x, u):
    return (u + x) ** 2

# Производная правой части по u (для метода Ньютона)
def df_du(x, u):
    return 2.0 * (u + x)

# Точное решение
def u_exact(x):
    return np.tan(x) - x

# Параметры задачи
a, b = 0.0, 1.0
u0 = 0.0
p = 3                     # порядок явного метода (по варианту)
h = 0.1
h2 = h / 2.0

# ------------------------------------------------------------------
# Неявный метод трапеций с решением уравнения методом Ньютона
# ------------------------------------------------------------------
def implicit_trapezoidal(f, df_du, a, b, u0, h, tol=1e-12, max_iter=50):
    n_steps = int(round((b - a) / h))
    x = np.linspace(a, b, n_steps + 1)
    u = np.zeros(n_steps + 1)
    u[0] = u0
    for i in range(n_steps):
        xn = x[i]
        un = u[i]
        x_next = xn + h
        # Начальное приближение: явный Эйлер
        u_guess = un + h * f(xn, un)
        u_new = u_guess
        for _ in range(max_iter):
            F = u_new - un - 0.5 * h * (f(xn, un) + f(x_next, u_new))
            dF = 1.0 - 0.5 * h * df_du(x_next, u_new)
            delta = F / dF
            u_new -= delta
            if abs(delta) < tol:
                break
        u[i+1] = u_new
    return x, u

# ------------------------------------------------------------------
# Явный метод Рунге‑Кутты (третий порядок, p=3)
# ------------------------------------------------------------------
def runge_kutta(f, a, b, u0, h, p):
    n_steps = int(round((b - a) / h))
    x = np.linspace(a, b, n_steps + 1)
    u = np.zeros(n_steps + 1)
    u[0] = u0
    for i in range(n_steps):
        xn = x[i]
        un = u[i]
        if p == 2:
            k1 = f(xn, un)
            k2 = f(xn + h, un + h * k1)
            u[i+1] = un + h * (k1 + k2) / 2.0
        elif p == 3:
            k1 = f(xn, un)
            k2 = f(xn + h/2.0, un + h/2.0 * k1)
            k3 = f(xn + h, un - h * k1 + 2.0 * h * k2)
            u[i+1] = un + h * (k1 + 4.0*k2 + k3) / 6.0
        else:
            raise ValueError("Только p=2 или p=3")
    return x, u

# ------------------------------------------------------------------
# Вычисление решений
# ------------------------------------------------------------------
# Неявный метод трапеций
x_h_imp, y_h_imp = implicit_trapezoidal(f, df_du, a, b, u0, h)
x_h2_imp, y_h2_imp = implicit_trapezoidal(f, df_du, a, b, u0, h2)

# Явный метод Рунге‑Кутты
x_h_exp, y_h_exp = runge_kutta(f, a, b, u0, h, p)
x_h2_exp, y_h2_exp = runge_kutta(f, a, b, u0, h2, p)

# ------------------------------------------------------------------
# Оценка погрешности (явный метод, h/2)
# ------------------------------------------------------------------
u_exact_h2 = u_exact(x_h2_exp)
max_error = np.max(np.abs(u_exact_h2 - y_h2_exp))
print("РЕЗУЛЬТАТЫ ДЛЯ ВАРИАНТА 8 (p = 3)")
print(f"Максимальная ошибка |точное - y_h/2| = {max_error:.3e}")

# ------------------------------------------------------------------
# Оценка порядка точности (правило Рунге)
# ------------------------------------------------------------------
diff_at_coarse = np.abs(y_h_exp - y_h2_exp[::2])
max_diff = np.max(diff_at_coarse)
richardson_est = max_diff / (2.0**p - 1.0)
print(f"max |y_h - y_h/2| в общих узлах = {max_diff:.3e}")
print(f"Оценка погрешности по Ричардсону = {richardson_est:.3e}")

# ------------------------------------------------------------------
# Построение графика
# ------------------------------------------------------------------
x_dense = np.linspace(a, b, 200)
u_exact_dense = u_exact(x_dense)

plt.figure(figsize=(8, 5))
plt.plot(x_dense, u_exact_dense, 'k-', linewidth=2, label='Точное решение')
plt.plot(x_h2_exp, y_h2_exp, 'ro', markersize=4, label=f'Явный РК (p={p}), h={h2}')
plt.xlabel('x')
plt.ylabel('u(x)')
plt.title('Решение задачи Коши (вариант 8)')
plt.legend()
plt.grid(True)
plt.savefig('solution_plot_variant8.png', dpi=150)
plt.show()

# ------------------------------------------------------------------
# Дополнительно: вывод таблицы значений
# ------------------------------------------------------------------
print("\n  x        точное       y_h/2        ошибка")
for i in range(0, len(x_h2_exp), max(1, len(x_h2_exp)//10)):
    xi = x_h2_exp[i]
    exact_i = u_exact(xi)
    num_i = y_h2_exp[i]
    print(f"{xi:.3f}   {exact_i:.6f}   {num_i:.6f}   {abs(exact_i-num_i):.2e}")
```
